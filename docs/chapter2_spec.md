## パート1：企画仕様（ストーリー視点）

第2章は、**「昇格目前のタナベッカムが、自分から不遇への扉を開けてしまう章」**。

ドラクエ型の自由探索RPGを基本にしながら、一定時間ごとに公式戦が発生。
重要な試合では既存のリアルタイム自由移動型サッカーモードを使用する。

ストーリー進行と試合タイマーは別管理。次の公式戦まで実プレイ10分。
ゲームを閉じている間は進行しない。最低試合数だけ設定し、それを満たせば
メインストーリーを早く進めてもよい。逆にストーリーを進めず、育成・探索・
試合を何度でも繰り返すことも可能。

### 前半「天罰のタナベッカム」

FC山陽TIGAKUは絶好調。連戦連勝でJ昇格が見えている状態から始まる。田辺も
レギュラー。普通に勝てるので、プレイヤーは自由に練習・探索・買い物・試合
ができる。

昇格祈願のため神社へ。奥に何の説明もなく宝箱があり、開けると「お賽銭を
手に入れた！」。盗む／盗まないの選択肢は出さない。その瞬間、画面端に
「ひろし君の息子」が初登場（セリフ「…………」のみでもよい）。田辺は気づか
ない。実はもともと田辺の大ファンだったが、賽銭を取るところを目撃して感情
が変わる——という裏設定は第2章では説明せず、後の伏線として保持する。

直後にボス「神」が出現。通常プレイではほぼ勝てないが完全な強制敗北には
しない。異常な育成なら理論上撃破可能。倒すと隠し称号「バロンドールタナベ」
を永久獲得（能力補正なし）。

神に勝っても負けても、「賽銭を取ったこと」自体が罰当たりなので天罰は発生
する。

### 天罰発動〜不遇ルート

神社イベント後、連戦連勝だったTIGAKUが急に勝てなくなる（不遇ルート）。
完全な強制敗北にはしないが、基本的にかなり勝ちにくい。味方AIのミス・
こぼれ球・ポスト・相手の決定力上昇・不運な失点などで表現する。RPG側にも
影響し、戦闘・宝箱・逃走などで不運が起きやすくなる。

ひろし君の息子が「罰当たりなことをしたから負けている」という空気をサポー
ターへ広げ、「天罰のタナベッカム」と呼ばれ始める。それでもひろし君は田辺
を使い続け、批判がひろし君自身にも及び、最終的に**ひろし君、更迭**。これに
はひろし君の息子が間接的に関わっている（これも伏線、第2章では説明しない）。

### ヒグチビッチ加入〜ベンチ試合

ひろし君更迭後、ヒグチビッチが颯爽と加入。能力は田辺より圧倒的に高い
（シュート・ドリブル・パス・判断力）。ただし田辺の走力・スタミナは独自の
強みとして残す。新監督はヒグチビッチをレギュラー起用、田辺はベンチへ。

ここで新システム「操作できない試合モード」。試合画面は始まるが田辺は操作
不可（ベンチ）。AI同士で試合が進み、ヒグチビッチが活躍する。田辺はベンチ
横のアップエリアでのみ操作可能（軽く走る・ダッシュ・ストレッチ・監督の前
を通る等）。これが内部値 `managerAppeal` を増加させ、一定値以上で途中出場
候補になる。

途中出場できても、ヒグチビッチから田辺へはなかなかパスが来ない（意地悪で
はなくAIの得点期待値判断）。新操作「パス要求」ボタンを追加（ボール非保持
時のみ、連打しすぎると `teamTrust` が下がって逆効果）。

第2章から「守備」ボタン（1ボタン方式）も追加。距離・田辺の守備力・相手の
ドリブル力・スタミナで判定。成功でボール奪取、失敗で抜かれる。試合ごとに
`defensiveContribution` を内部記録し、守備をしないと監督から注意イベント。
この値は後のサイドバック評価にも使う。

ヒグチビッチ活躍でTIGAKUは勝ち始め、**J昇格達成**。直後、ヒグチビッチは
颯爽と**アーセナル移籍**（長い別れ演出はなし）。

### J1編〜お祓い〜💩システム

ヒグチビッチ不在で再び田辺に注目が集まるが、J1では通用しない（相手の
守備・判断・ポジショニングを突く強さに設定）。

苦戦するとひろし君の息子が再び動き、「まだ呪われてるんじゃない？」という
空気を作る。サポーターに「お祓いしてこい！」と圧力をかけられ、再び神社へ
（第2次神社クエスト「お祓い」）。

お祓いの結果は既存の「運」パラメータで決まるが、**プレイヤーには運が関係
していることを一切説明しない**。結果だけ3段階で表示する：

- 完全解除：「タナベッカムの呪いは完全に解けた！」→ `curseLevel = 0`
- 一部解除：「タナベッカムの呪いは少しだけ解けた！」→ `curseLevel -= 1`（最低0）
- さらに呪われた：「なんと！タナベッカムはさらに呪われた！」→ `curseLevel += 1`（最大3）

`curseLevel >= 1` の間、田辺の頭に💩を常時表示（フィールド・戦闘・ベンチ・
試合・イベント全画面、個数は curseLevel と同じ）。3個になった瞬間、隠し
称号「うんこまん」を永久獲得（呪いが解けても称号は残る）。再お祓いは時間
とG（`EXORCISM_COST`）が許す限り何度でも可能。

### サイドバック／整体バイト／逮捕〜エンディング

J1後半、出場機会が減った田辺はベンチへ。アップで監督にアピールし、途中
出場を勝ち取ると監督に「サイドバックでもしておけ」と言われる。プレイヤー
選択：「サイドバックで出る」／「俺はトップ下です」。サイドバックを選ぶと
実際にSBとして出場、活躍度はそれまで育てた走力・スタミナ・守備・パス・
ドリブルで決まる（固定しない）。活躍すれば `sideBackExperience` が増え、
後のスペイン編で利用できる。どちらを選んでも出場機会自体は少ない
（「プロなのに試合に出られない」状態を体験させる）。

第2章後半から「出場給」導入：実際に出場した試合のみG獲得
（`MATCH_PAYMENT`）。ベンチのみは0G。

出場機会減少による金欠から「整体師アルバイト」を解放。序章の身体ケア
ポイントを引き継ぐ。患者NPCの症状（例：「右肩が痛い」）に対し施術箇所を
選択するミニゲーム。正解でG＋身体ケアポイント、不正解で報酬減少／0G。
身体ケアポイントが高いとヒントが出ることがある。整体ばかりやると練習・
試合の時間を失うトレードオフを持たせる。

ストーリー後半、整体師が悪徳だったことが発覚し警察が突入・逮捕。田辺は
パニックで逃走開始 → 最終ダンジョン「警察包囲網」。隠れるゲームではなく
大量の警察官とのRPG戦闘。表現はコミカルにし、死亡・重傷表現は禁止（転ばせ
る・吹き飛ばす・気絶・戦闘不能程度）。通常より敵遭遇率高め。田辺の走力・
スタミナが逃走・行動に有利（サッカー以外で最大の長所を使うギャグとして
成立させる）。出口到達で「タナベッカムは逃げ切った！」。

田辺は一人になり、サッカーでも居場所がなく整体師も逮捕、どん底状態。
そこへ電話——スペイン2部クラブからオファー。短い会話イベントの後、
**第2章 CLEAR → 第3章「スペイン編」へ続く**。

### 隠し称号まとめ

- **バロンドールタナベ**：神を撃破
- **うんこまん**：`curseLevel` が3に到達

両方同時取得も可能。

## パート2：技術仕様（実装向け）

### 引き継ぐ既存システム

RPGレベル・EXP・HP・攻撃力・防御力・所持金・装備・アイテム・サッカー
能力・習得済み必殺技・身体ケアポイント（`seitaiPoint`）・称号（新規追加）・
ストーリーフラグ・セーブデータ。既存セーブとの互換性を維持し、保存形式に
`version` を必ず持たせる（既存の仕組みをそのまま踏襲）。

### 第2章開始状態

FC山陽TIGAKUは好調、田辺はレギュラー、チームは昇格争い中。序盤数試合は
普通に勝敗判定（不遇補正なし）。育成状態と操作技術で勝敗が決まる。

### 基本ループ

自由行動 → 実プレイ10分経過（`MATCH_INTERVAL`） → 公式戦 → 試合終了 →
自由行動再開。ゲームを閉じている間はタイマー停止。メニュー等ゲーム進行を
止めるべき画面でも停止可。

### ストーリー進行と試合の分離

メインストーリーはNPC会話・指定地点到達・クエストクリア・イベントフラグ
で進行し、試合数だけで自動進行させない。各大型イベントに
`minimumMatches` を設定し、それを超えたらプレイヤーがイベントを起こすまで
何試合でも続行可能（育成・金策・やり込みが可能な構造）。

```js
storyEvent = { id: "shrine_event", minimumMatches: 2, requiredFlags: [] }
```

### 主要定数（`js/data/chapter2.js` に定義）

```js
MATCH_INTERVAL       // 次回公式戦までの実プレイ秒数（10分）
MIN_MATCHES          // 各イベント解放に必要な最低試合数
GOD_STATS            // ボス「神」の能力値（hp/attack/defense/speed/luck）
MISFORTUNE_MODIFIER  // 天罰・不遇時の各種不利補正
EXORCISM_COST        // お祓いに必要なG・時間
MATCH_PAYMENT        // 出場給
CURSE_MAX            // 呪いレベルの最大値（3）
```

### 天罰・不遇補正の例

味方AI判断低下／味方パス精度低下／味方シュート決定率低下／相手決定率
上昇／こぼれ球が相手へ行きやすい／ポスト発生率上昇／不運な失点イベント／
田辺へのパス頻度低下。値はすべて `MISFORTUNE_MODIFIER` に定数化し、勝利
不能にはしない。RPG側にも波及：逃走成功率低下／敵遭遇率上昇／宝箱ハズレ率
上昇／敵先制率上昇／店イベントで損／一部ランダムイベント悪化。

### ベンチ試合・アップ・パス要求・守備ボタン

ベンチ中は通常の試合画面へ入るが田辺を操作不可（AI同士の試合を見る）。
アップエリアでのみ操作可能で `managerAppeal` を増加させ、一定値で途中出場
候補になる。途中出場後は「パス要求」ボタン（ボール非保持時のみ）を追加し、
連打しすぎると `teamTrust` が低下してかえってパスが来にくくなる。
「守備」ボタン（1ボタン）は距離・田辺の守備力・相手ドリブル力・スタミナ
で判定し、試合ごとに `defensiveContribution` を内部記録する。

### 呪い・お祓い

お祓き結果は既存の「運」パラメータで判定するが、プレイヤーには一切明示
しない。ステータス画面でも非表示（隠しステータス扱い）。結果は3段階
（完全解除 `curseLevel = 0` ／一部解除 `curseLevel -= 1`（最低0）／さらに
呪われた `curseLevel += 1`（最大 `CURSE_MAX`））。`curseLevel >= 1` の間、
全画面で田辺の頭に💩を `curseLevel` 個数分常時表示。`curseLevel` が
`CURSE_MAX` に達した瞬間に称号「うんこまん」を永久付与。

### サイドバック・出場給・整体バイト

サイドバック選択は分岐（`sideBackAccepted`）。出場した場合のみ活躍度を
`sideBackExperience` に加算し、それまでの走力・スタミナ・守備・パス・
ドリブルの育成状況で結果を決める。出場給（`MATCH_PAYMENT`）は実際に出場
した試合のみ加算、ベンチのみは0G。

整体師アルバイトは `seitaiPoint`（身体ケアポイント）を利用するミニゲーム。
症状に対して施術箇所を選択し、正解でG＋ポイント、不正解で減額。
`massageJobUnlocked` / `massageWorkCount` で解放・回数を管理。

### 警察逃走ダンジョン

通常のRPGダンジョンとして実装。コミカル表現に限定し、死亡・重傷表現は
禁止。敵遭遇率を高めに設定し、田辺の走力・スタミナ育成が有利に働く数値
設計にする。

### 第2章セーブ項目

```js
chapter2: {
  matchCount,
  nextMatchTimer,
  divinePunishment,
  misfortuneMode,
  godDefeated,
  hiroshiSonSeen,
  hiroshiDismissed,
  higuchibitchJoined,
  higuchibitchTransferred,
  managerAppeal,
  teamTrust,
  defensiveContribution,
  curseLevel,
  sideBackExperience,
  sideBackAccepted,
  massageJobUnlocked,
  massageWorkCount,
  policeDungeonCleared,
  storyFlags
}
```

既存項目（`titles`, `seitaiPoint`, `soccerSkills`, `equip`, `gold`,
`level`, `exp`, `learnedSkills` など）も引き続き保存する。`titles` は
序章時点では未実装のため、第2章の土台実装時に `player.titles: []` として
新設する。

### 隠し称号の付与条件

- 「バロンドールタナベ」：神を撃破
- 「うんこまん」：`curseLevel` が `CURSE_MAX`（3）に到達

### 実装上の重要事項

- 既存システム（序章）を壊さない。序章を作り直さない。
- 値は定数化し、後から調整しやすい構造にする。
- 可能な限り `engine/` `data/` などで責務分離する（本プロジェクトの既存
  構成：`js/engine/*.js` がロジック、`js/data/*.js` が定数・マスタデータ）。
- 神戦・不遇試合・J1試合も、原則として理論上は勝利可能な設計にする
  （固定敗北を避ける）。通常プレイでは非常に難しいバランスにはしてよい。

### 素材方針

クロ（実装側）で完成画像は生成しない。既存方針どおり
`assets/{characters,enemies,bosses,backgrounds,maps,ui,effects}/` に分離
し、仮画像・プレースホルダーで実装、後から画像だけ差し替え可能にする。
新規素材候補：ひろし君の息子／ヒグチビッチ／神／神社／💩表示／新監督／
整体師／整体客／警察官／ベンチ／アップエリア／J1用スタジアム。

## 進め方（フェーズ分割）

大規模なため、以下のフェーズに分けて実装する。各フェーズごとにローカル
確認 → push → デプロイ確認まで行う。

1. **土台**：定数ファイル(`chapter2.js`)、セーブデータ拡張、第2章開始〜
   自由行動、試合タイマー（10分）
2. **通常試合ループ**：公式戦・勝敗判定、`minimumMatches` によるイベント
   解放
3. **神社クエスト①・神戦・天罰**：神社マップ、賽銭宝箱、ひろし君の息子
   登場、神戦、天罰フラグ・不遇補正
4. **監督更迭・ヒグチビッチ加入**：NPC反応変化、更迭イベント、加入演出、
   ベンチ試合モード、アップ・パス要求・守備ボタン
5. **昇格・移籍・J1**：昇格、ヒグチビッチ移籍、J1難易度
6. **お祓い・呪い**：神社②、お祓い判定（運非公開）、💩表示、うんこまん
   称号
7. **サイドバック・整体バイト**：出場選択、出場給、整体ミニゲーム
8. **逮捕・逃走ダンジョン・エンディング**：悪徳整体師逮捕、警察ダンジョン、
   スペインオファー、第2章CLEAR
9. **仕上げ**：完成報告（上記「完成後の報告内容」一式）
